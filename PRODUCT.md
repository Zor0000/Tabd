# Tabd

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

User-specified Next.js App Router, TypeScript, Tailwind, shadcn-style Radix components, Lucide, Motion, Supabase Auth/Postgres, and WXT Chrome extension.

## Users

Developers, designers and technology enthusiasts saving useful websites during daily work.

## Product Purpose

Save → organize → find → revisit → use. The dashboard comes first, with the extension using the same persisted library.

## Capabilities and Constraints

URL is the only required save input. Optional collection, tags, notes and status. Collections may nest. Archive is independent of status. Secure per-user ownership. No AI, social features or paid subscriptions.

## Brand Commitments

The user requests Linear's clean interface and Raindrop's visual cards, neutral surfaces and a restrained accent. Original identity. Product name Tabd confirmed by the user. The user selected burnt copper to replace the initial violet accent.

## Evidence on Hand

User's detailed pasted brief. No existing code, visual assets or customer data. Preview content must be labeled and must never imply account persistence.

## Product Principles

Fast saving; search before folder browsing; clear feedback; real persisted operations; dashboard before extension.

## Open decisions

User confirmed they have not created a Supabase project. Deliver schema and setup instructions; do not change the unrelated Setzo project.
