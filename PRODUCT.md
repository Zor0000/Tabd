# Tabd

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

User-specified Next.js App Router, TypeScript, Tailwind, shadcn-style Radix components, Lucide, Motion, Supabase Auth/Postgres, and WXT Chrome extension.

## Users

Developers, designers and technology enthusiasts saving useful websites during daily work.

## Product Purpose

Save → organize → find → revisit → use. The dashboard comes first, with the extension using the same persisted library.

## Capabilities and Constraints

URL is the only required save input. Optional collection, tags, notes and status. Collections may nest. Archive is independent of status. Secure per-user ownership. No AI, social features or paid subscriptions.

## Brand Commitments

The user requests Linear's clean interface and Raindrop's visual cards, neutral surfaces and a restrained accent. Original identity. Product name Tabd confirmed by the user. The user replaced burnt copper with vivid orange inspired by the Ghost core site. Preserve the clean dashboard and original Tabd identity; the account entry surface pairs silver engraved geometric lettering with a quiet form.

## Evidence on Hand

User's detailed brief and the implemented dashboard, extension, and account entry surface. Preview content must be labeled and must never imply account persistence.

## Product Principles

Fast saving; search before folder browsing; clear feedback; real persisted operations; dashboard before extension.

## Open decisions

Supabase is configured in the current app. Authentication has not been verified end to end with a real account. Keep the unrelated Setzo project untouched.
