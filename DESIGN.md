# Tabd design system

The supplied brief pins the visual direction: Linear clarity with visual resource cards. Use conventional dashboard navigation and controls. Operate mode.
A quiet, warm white workspace with a pale neutral rail, graphite type, fine borders and restrained burnt copper selection. Copper (#B65335) owns the logo, primary actions and focus; pale clay (#F7EDE7) supports selection, with darker copper (#9D452D) for text. Dark mode uses charcoal surfaces with softer copper (#DC997C) actions, clay text (#E7AE92) and warm dark selections (#382A24). Reference status uses slate; success and exploration keep their distinct semantic colors. Geist sans. Small uppercase labels belong only to navigation groups; no marketing eyebrow or hero.
Signature: each saved website has a wide preview above a compact resource record; status is directly editable below. Preview content is factual, and the preview library is explicitly labeled.
Desktop: 236px navigation, 64px top toolbar, generous 40px workspace inset. Three card columns at common laptop widths. Compact list mode has the same actions. Mobile: off-canvas navigation, two then one card columns, accessible controls.
Tokens: 8px rhythm, 14px body, 30px heading, 12px metadata, 12px cards, 8px buttons. Motion is limited to the save sheet and small hover/focus transitions; reduced motion honored.
All actions must work or explain configuration requirements. Empty real accounts start empty. Examples never silently become account data.
